SK Textiles website - GitHub Pages package

1. Unzip this file.
2. Upload EVERYTHING (index.html, .nojekyll and the assets folder) to the root of your GitHub repository.
3. Repository Settings > Pages > Deploy from a branch > main / (root).
4. Open the Pages link. Product images load from the assets/images folder, so keep it next to index.html.

To continue editing later: open index.html (or the original file) and press Ctrl+Shift+E, or import this ZIP in Admin > Bulk Upload > Import.
